AgentCore Memory 交互式演示

AgentCore Memory 提供两大核心能力： Short-term Memory (STM) - 会话内的短期记忆，以及 Long-term Memory (LTM) - 跨会话的长期记忆。
架构概览

AgentCore Memory 整体架构：展示 STM 和 LTM 如何协同工作

步骤 1: Memory 资源管理

创建新的 Memory 资源

点击下方按钮创建 Memory 资源（同时包含短期记忆和长期记忆功能）。创建后会自动刷新下方的下拉选择框。

Memory 说明：一个 Memory 实例包含 STM（原始对话事件） 和 LTM（提取的语义记忆）。 每个用户最多创建 5个 Memory 资源。
创建代码示例
import time
from datetime import datetime
from bedrock_agentcore.memory import MemoryClient

# ========== 创建 Memory (包含 STM 和 LTM 功能) ==========
print("🚀 开始创建 Memory 资源（包含 STM 和 LTM 功能）")
client = MemoryClient(region_name="us-east-2")

# 创建带策略的 Memory
# - STM: 原始对话事件会即时存储
# - LTM: 5-15秒后异步提取语义和偏好信息
memory = client.create_memory_and_wait(
    name="username_Memory_xxx",
    strategies=[
        # 语义记忆策略: 提取重要的事实和信息
        {
            "semanticMemoryStrategy": {
                "name": "semantic_facts",
                "description": "提取用户提到的重要事实和信息",
                "namespaces": ["/strategies/{memoryStrategyId}/actors/{actorId}"]
            }
        },
        # 用户偏好策略: 提取用户的喜好和偏好
        {
            "userPreferenceMemoryStrategy": {
                "name": "user_preferences",
                "description": "提取用户的偏好、喜好和习惯",
                "namespaces": ["/strategies/{memoryStrategyId}/actors/{actorId}"]
            }
        }
    ],
    description="Memory with both STM (raw events) and LTM (extracted memories)",
    event_expiry_days=30  # 保存30天
)

print(f"✅ Memory 创建成功: {memory['id']}")
print(f"   - STM: 原始对话事件会即时存储")
print(f"   - LTM: 5-15秒后异步提取语义和偏好信息")

步骤 1: 介绍自己

                                
在下方输入你的信息，然后点击执行。STM 会存储这次对话。


                                
步骤 1 代码示例:

                                


from bedrock_agentcore.memory.constants import ConversationalMessage, MessageRole

# 假设 stm_manager 和 bedrock_runtime 已在上面初始化完成

# ========== 步骤 1: 存储第一条对话 ==========
user_message = "我叫张三，是一名软件工程师"
session_id = "session-123"
actor_id = "user-001"

# 调用 LLM 生成回复
response = bedrock_runtime.converse(
    modelId="us.anthropic.claude-sonnet-4-5-20250929-v1:0",
    messages=[{"role": "user", "content": [{"text": user_message}]}]
)
assistant_response = response['output']['message']['content'][0]['text']

# 存储对话到 STM
stm_manager.add_turns(
    actor_id=actor_id,
    session_id=session_id,
    messages=[
        ConversationalMessage(user_message, MessageRole.USER),
        ConversationalMessage(assistant_response, MessageRole.ASSISTANT)
    ]
)
print(f"已存储对话到 STM，Session ID: {session_id}")

步骤 2: 询问之前的信息

                                
询问与步骤 1 相关的问题，测试 STM 的记忆能力。


                                
步骤 2 代码示例:

                                


from bedrock_agentcore.memory.constants import ConversationalMessage, MessageRole

# 假设 stm_manager 和 bedrock_runtime 已在上面初始化完成
# session_id 和 actor_id 来自步骤 1

# ========== 步骤 2: 基于历史对话回答 ==========
follow_up_question = "你还记得我的职业是什么吗?"

# 检索最近的对话历史
recent_turns = stm_manager.get_last_k_turns(
    actor_id=actor_id,
    session_id=session_id,
    k=5  # 最近 5 轮对话
)

# 构建上下文
context = ""
for turn in recent_turns:
    for msg in turn:
        role = "用户" if msg.get('role') == MessageRole.USER.value else "助手"
        text = msg.get('content', {}).get('text', '')
        context += f"{role}: {text}\n"

# 调用 LLM (带历史上下文)
response = bedrock_runtime.converse(
    modelId="us.anthropic.claude-sonnet-4-5-20250929-v1:0",
    messages=[{"role": "user", "content": [{"text": follow_up_question}]}],
    system=[{"text": f"历史对话:\n{context}"}]
)
assistant_response = response['output']['message']['content'][0]['text']

# 存储新的对话
stm_manager.add_turns(
    actor_id=actor_id,
    session_id=session_id,
    messages=[
        ConversationalMessage(follow_up_question, MessageRole.USER),
        ConversationalMessage(assistant_response, MessageRole.ASSISTANT)
    ]
)
print(f"助手回答: {assistant_response}")

# 假设 ltm_manager 和 bedrock_runtime 已在上面初始化完成

session_id_1 = "ltm-session-1"
actor_id = "user-001"

# 调用 LLM
response = bedrock_runtime.converse(
    modelId="us.anthropic.claude-sonnet-4-5-20250929-v1:0",
    messages=[{"role": "user", "content": [{"text": user_preference}]}]
)
assistant_response = response['output']['message']['content'][0]['text']

# 存储到 LTM
ltm_manager.add_turns(
    actor_id=actor_id,
    session_id=session_id_1,
    messages=[
        ConversationalMessage(user_preference, MessageRole.USER),
        ConversationalMessage(assistant_response, MessageRole.ASSISTANT)
    ]
)
print("已存储偏好到 LTM")
print("⏳ LTM 正在异步提取偏好信息，需要 10-15 秒...")

# 等待 LTM 异步提取 (10-15秒)
time.sleep(15)

步骤 2 代码示例:

                                


from bedrock_agentcore.memory.constants import ConversationalMessage, MessageRole

# 假设 ltm_manager 和 bedrock_runtime 已在上面初始化完成
# actor_id 来自步骤 1

# ========== 步骤 2: 新会话中检索记忆 (Session 2) ==========
user_question = "能给我一些编程建议吗?"
session_id_2 = "ltm-session-2"  # 注意：这是一个新的会话 ID

# 从 LTM 检索相关记忆
memories = ltm_manager.search_long_term_memories(
    query=user_question,
    namespace_prefix="/",
    top_k=3
)

# 构建上下文
context = ""
for memory in memories:
    content = memory.get('content', {})
    text = content.get('text', '') if isinstance(content, dict) else str(content)
    context += f"- {text}\n"

print(f"从 LTM 检索到 {len(memories)} 条相关记忆")

# 调用 LLM (带长期记忆上下文)
response = bedrock_runtime.converse(
    modelId="us.anthropic.claude-sonnet-4-5-20250929-v1:0",
    messages=[{"role": "user", "content": [{"text": user_question}]}],
    system=[{"text": f"用户的长期记忆:\n{context}"}]
)
assistant_response = response['output']['message']['content'][0]['text']

# 存储新的对话
ltm_manager.add_turns(
    actor_id=actor_id,
    session_id=session_id_2,
    messages=[
        ConversationalMessage(user_question, MessageRole.USER),
        ConversationalMessage(assistant_response, MessageRole.ASSISTANT)
    ]
)
print(f"助手回答: {assistant_response}")

STM vs LTM 对比表

                        

                            

                                
                                    

                                        特性
                                        Short-term Memory (STM)
                                        Long-term Memory (LTM)
                                    

                                
                                
                                    

                                        存储内容
                                        原始对话轮次
                                        提取的偏好和语义信息
                                    

                                    

                                        处理时间
                                        即时 (<1秒)
                                        异步 (5-15秒)
                                    

                                    

                                        记忆范围
                                        当前会话内
                                        跨会话、持久化
                                    

                                    

                                        信息完整性
                                        完整保留
                                        提取摘要
                                    

                                    

                                        检索方式
                                        按时间顺序
                                        语义相关性
                                    

                                    

                                        适用场景
                                        对话连贯性、上下文维护
                                        用户画像、偏好记忆
