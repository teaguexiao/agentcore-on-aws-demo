## 简介

Amazon Bedrock AgentCore Runtime 是一个安全的、无服务器运行时环境，专为部署和扩展 AI Agent 和工具而设计。它支持任何框架、模型和协议，使开发者能够以最少的代码更改将本地原型转换为生产就绪的解决方案。

### 核心价值

- **快速部署**: 从本地开发到生产环境只需几分钟
- **灵活性**: 支持任何 AI 框架和模型
- **安全性**: AWS 托管的安全运行时环境
- **可扩展性**: 自动扩展，无需管理基础设施
- **集成性**: 与其他 AgentCore 功能无缝集成

---

## 核心特性

### 1. 框架和模型的灵活性

- **支持任何 AI 框架**: Strands Agents、LangChain、LangGraph、CrewAI 等
- **支持任何模型**:
  - Amazon Bedrock 中的模型（Claude, Titan 等）
  - 自托管模型
  - 第三方模型 API

### 2. 无服务器架构

- **自动扩展**: 根据负载自动调整资源
- **按需计费**: 只为实际使用的计算资源付费
- **零运维**: 无需管理服务器和基础设施

### 3. 与 AgentCore 生态集成

AgentCore Runtime 通过统一的 SDK 与其他 Amazon Bedrock AgentCore 功能集成:

- **AgentCore Memory**: 短期和长期记忆管理
- **AgentCore Gateway**: API 网关和流量管理
- **AgentCore Observability**: 监控、日志和追踪
- **AgentCore Tools**: 浏览器自动化、代码解释器等工具

### 4. 多种部署方式

支持两种灵活的部署方式，满足不同场景需求:

- **Direct Code Deployment**: 适合 Python 项目，简单快捷
- **Container Deployment**: 适合复杂依赖和多语言环境

### 5. 开发体验优化

- **轻量级 SDK**: 最小化代码侵入
- **本地测试**: 支持本地调试和测试
- **快速迭代**: 支持热更新和版本管理

## 部署方式

### Direct Code Deployment (直接代码部署)

#### 适用场景
- Python 项目
- 依赖项相对简单
- 快速原型开发
- 标准 Python 库

#### 工作流程
```
本地开发 → 打包 .zip → 上传 S3 → 创建 Runtime → 部署完成
```

#### 优势
- **简单快捷**: 无需 Docker，直接打包 Python 代码
- **部署速度快**: .zip 文件小，上传和部署迅速
- **成本更低**: S3 存储成本低于 ECR

#### 技术要求
- Python 3.10+
- 代码和依赖打包为 .zip 文件
- 为 ARM64 架构编译依赖

---

### Container Deployment (容器部署)

#### 适用场景
- 需要自定义运行时环境
- 使用非 Python 语言
- 复杂的系统依赖
- 严格控制运行环境

#### 工作流程
```
本地开发 → 构建 Docker 镜像 → 推送 ECR → 创建 Runtime → 部署完成
```

#### 优势
- **完全控制**: 自定义运行时环境和依赖
- **多语言支持**: Python, Node.js, Java, Go 等
- **可移植性**: Docker 镜像可在任何环境运行
- **一致性**: 开发、测试、生产环境完全一致

#### 技术要求
- Docker 和 Docker Buildx
- ARM64 架构的 Docker 镜像
- FastAPI 或类似 Web 框架
- 实现 `/invocations` 和 `/ping` 端点

---

### 部署方式对比

| 特性 | Direct Code Deployment | Container Deployment |
|------|------------------------|----------------------|
| **部署包类型** | .zip 文件 | Docker 镜像 |
| **存储位置** | S3 | ECR |
| **架构要求** | ARM64 Python 包 | ARM64 Docker 镜像 |
| **语言支持** | Python 专用 | 任何语言 |
| **部署速度** | 快（秒级） | 中等（分钟级） |
| **复杂度** | 低 | 中等 |
| **灵活性** | 中等 | 高 |
| **适用场景** | 标准 Python 项目 | 复杂环境/多语言 |
| **成本** | 较低 | 较高 |

### 选择建议

**选择 Direct Code Deployment 如果:**
- ✅ 项目是 Python 编写
- ✅ 依赖项都可以通过 pip 安装
- ✅ 不需要系统级依赖
- ✅ 追求快速部署

**选择 Container Deployment 如果:**
- ✅ 需要自定义运行时
- ✅ 使用非 Python 语言
- ✅ 需要系统级依赖（如 ffmpeg、imagemagick）
- ✅ 对环境一致性有严格要求

## 应用场景

### 1. 实时交互式 AI Agent

**场景描述**: 客户服务聊天机器人，需要快速响应用户查询

**技术方案**:
- 使用 Runtime 部署对话 Agent
- 集成 AgentCore Memory 保存对话历史
- 使用 AgentCore Tools 查询知识库

**优势**: 低延迟、高并发、自动扩展

---

### 2. 长时间运行的复杂工作流

**场景描述**: 数据分析 Agent，需要执行多步骤数据处理

**技术方案**:
- 使用 Container Deployment 部署自定义环境
- 集成 AgentCore Code Interpreter 执行数据分析
- 使用 Strands Agents 编排工作流

**优势**: 支持长时间运行、容错、状态持久化

---

### 3. 多模态 AI 处理

**场景描述**: 图像分析和生成工具，处理用户上传的图片

**技术方案**:
- Container Deployment 包含图像处理库
- 调用 Bedrock 多模态模型
- 集成 S3 存储处理结果

**优势**: 支持多种数据格式、灵活扩展

---

### 4. 自动化浏览器操作

**场景描述**: 网页数据采集和自动化测试

**技术方案**:
- 使用 Runtime 部署 Browser Agent
- 集成 AgentCore Browser Tool
- 定时触发或事件驱动

**优势**: 无需维护浏览器基础设施、自动扩展

## 技术优势

### 1. 开发效率提升

**最小化代码侵入**:
```python
# 只需添加一个装饰器
from bedrock_agentcore import BedrockAgentCoreApp

app = BedrockAgentCoreApp()

@app.entrypoint
def invoke(payload):
    # 你的 Agent 逻辑
    return {"result": "..."}
```

**本地测试支持**:
```bash
# 本地运行测试
uv run main.py

# curl 测试
curl -X POST http://localhost:8080/invocations \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Hello"}'
```

### 2. 生产就绪

- **自动健康检查**: 内置 `/ping` 端点
- **日志集成**: 自动发送到 CloudWatch Logs
- **监控指标**: 自动收集性能指标
- **版本管理**: 支持多版本并存和金丝雀部署

### 3. 安全性

- **网络隔离**: 支持 VPC 部署
- **IAM 集成**: 细粒度权限控制
- **加密**: 传输和存储数据加密
- **审计日志**: 完整的操作审计

### 4. 成本优化

- **按需付费**: 无闲置成本
- **自动缩容**: 无流量时自动缩减到零
- **资源共享**: 多个 Agent 共享基础设施

### 调用流程

```
1. 客户端发起请求
   POST /invocations
   {
     "prompt": "用户输入"
   }

2. Runtime 接收请求
   - 验证身份
   - 路由到 Agent

3. Agent 处理逻辑
   - 解析请求
   - 调用模型
   - 使用工具
   - 生成响应

4. 返回结果
   {
     "output": {
       "message": "Agent 响应",
       "timestamp": "..."
     }
   }
```

## 与其他服务对比

### vs AWS Lambda

| 特性 | AgentCore Runtime | AWS Lambda |
|------|-------------------|------------|
| **专注领域** | AI Agent 部署 | 通用计算 |
| **集成** | AgentCore 生态深度集成 | AWS 服务广泛集成 |
| **运行时长** | 支持最长8小时的运行时间 | 最长 15 分钟 |
| **冷启动** | 优化的 AI 场景冷启动 | 标准冷启动 |
| **开发体验** | AI Agent 专用 SDK | 通用开发框架 |

### vs 自建容器服务

| 特性 | AgentCore Runtime | ECS/EKS |
|------|-------------------|---------|
| **管理复杂度** | 低（托管） | 高（需要运维） |
| **扩展性** | 自动 | 需要配置 |
| **成本** | 按需计费 | 持续运行成本 |
| **部署速度** | 分钟级 | 较慢 |
| **灵活性** | 中等 | 非常高 |

## 总结

AgentCore Runtime 为 AI Agent 的生产部署提供了一个完整、灵活且易用的解决方案:

✅ **快速上手**: 最少的代码改动，快速从原型到生产
✅ **灵活部署**: 支持 Direct Code 和 Container 两种方式
✅ **生产就绪**: 内置监控、日志、健康检查等生产特性
✅ **无服务器**: 自动扩展，按需计费，零运维
✅ **深度集成**: 与 AgentCore 生态无缝集成

无论你是在构建简单的聊天机器人，还是复杂的多 Agent 系统，AgentCore Runtime 都能提供强大而灵活的支持。
