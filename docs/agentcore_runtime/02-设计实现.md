## 整体架构

### 技术栈
- **后端**: Python 3.11+ + FastAPI + boto3
- **前端**: Jinja2 + Vanilla JavaScript + Bootstrap 5
- **实时通信**: SSE (Server-Sent Events)
- **状态管理**: 内存字典 + localStorage

### 模块划分
```
agentcore-on-aws-demo/
├── agentcore_runtime_api.py        # Runtime API 后端模块
├── templates/
│   └── agentcore-runtime.html       # Runtime 页面模板
├── static/
│   ├── js/
│   │   ├── runtime.js               # Direct Code 前端逻辑
│   │   └── runtime-container.js     # Container 前端逻辑
│   └── css/
│       └── runtime.css              # 样式文件
└── deployment_packages/             # 部署包目录
    └── strands_agent/
        ├── deployment_package.zip   # Direct Code 部署包
        ├── Dockerfile               # Container 镜像定义
        └── agent.py                 # Agent 代码
```

#### boto3 客户端初始化
```python
def init_clients():
    """初始化 AWS 客户端"""
    global s3_client, agentcore_control_client, agentcore_client

    s3_client = boto3.client('s3', region_name=REGION)
    agentcore_control_client = boto3.client('bedrock-agentcore-control', region_name=REGION)
```

## 会话管理

### 4.1 后端会话存储

```python
# 全局会话字典
runtime_sessions = {
    "session_id_1": {
        "deployment_type": "code",  # or "container"
        "runtime_arn": "arn:aws:...",
        "runtime_id": "abc123",
        "created_at": 1699999999,

        # Direct Code 特有
        "s3_key": "demo_xxx/deployment.zip",

        # Container 特有
        "ecr_image_uri": "xxx.dkr.ecr.../repo:tag"
    }
}
```

### 4.2 会话生命周期

1. **创建**: 用户首次访问页面时生成 session_id
2. **持久化**:
   - 前端: localStorage 保存状态
   - 后端: 内存字典存储运行时信息
3. **清理**:
   - 用户主动删除 Runtime
   - 后台定期清理过期会话(可选)

## API 设计

### 5.1 SSE 响应格式

#### 流式消息
```
data: {"line": "正在执行步骤...", "done": false}
```


#### 错误响应
```json
{
  "status": "error",
  "detail": "错误描述"
}
```

## 数据流

### 6.1 Direct Code 部署流程

```
前端                     后端                      AWS
  │                       │                        │
  ├─点击"部署"───────────>│                        │
  │                       ├─检查 .zip 文件         │
  │                       ├─上传到 S3──────────────>│
  │<──SSE: 上传中────────┤                        │
  │                       │                        │
  │                       ├─create_agent_runtime──>│
  │<──SSE: 创建中────────┤                        │
  │                       │<──返回 ARN────────────┤
  │<──SSE: 完成──────────┤                        │
  │  (含 runtime_arn/id) │                        │
  │                       │                        │
  ├─保存到 localStorage   │                        │
  └─自动填充到后续步骤    │                        │
```

### 6.2 Container 部署流程

```
前端                     后端                      AWS
  │                       │                        │
  ├─点击"部署"───────────>│                        │
  │                       ├─构建镜像 URI           │
  │                       ├─create_agent_runtime──>│
  │<──SSE: 创建中────────┤  (containerConfiguration)
  │                       │<──返回 ARN────────────┤
  │<──SSE: 完成──────────┤                        │
  │                       │                        │
  ├─保存状态              │                        │
  └─自动填充              │                        │
```

## 关键实现细节

### Mock SSE 实现模式
```python
@router.get("/step2-stream")
async def step2_stream(session_id: str):
    async def generate():
        # 模拟输出
        yield f"data: {json.dumps({'line': '初始化项目...', 'done': False})}\n\n"
        await asyncio.sleep(0.5)
        yield f"data: {json.dumps({'line': '创建文件...', 'done': False})}\n\n"
        await asyncio.sleep(0.5)
        yield f"data: {json.dumps({'done': True, 'status': 'success'})}\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream")
```

### 真实 API 实现模式
```python
@router.get("/step5-deploy-stream")
async def deploy_stream(session_id: str):
    async def generate():
        try:
            yield f"data: {json.dumps({'line': '上传到 S3...', 'done': False})}\n\n"
            s3_client.upload_fileobj(...)

            yield f"data: {json.dumps({'line': '创建 Runtime...', 'done': False})}\n\n"
            response = agentcore_control_client.create_agent_runtime(...)

            # 保存会话
            runtime_sessions[session_id] = {...}

            yield f"data: {json.dumps({'done': True, 'runtime_arn': ...})}\n\n"
        except Exception as e:
            yield f"data: {json.dumps({'done': True, 'error': str(e)})}\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream")
```
