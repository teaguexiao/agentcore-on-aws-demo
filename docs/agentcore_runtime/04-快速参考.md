# AgentCore Runtime 快速参考

## 环境变量

### Direct Code 配置
```bash
AWS_ACCOUNT_ID=123456789012
AWS_REGION=us-west-2
S3_BUCKET=bedrock-agentcore-code-{account_id}-{region}
EXECUTION_ROLE_ARN=arn:aws:iam::{account_id}:role/AmazonBedrockAgentCoreSDKRuntime-{region}
DEPLOYMENT_PACKAGE_PATH=deployment_packages/strands_agent/deployment_package.zip
```

### Container 配置
```bash
CONTAINER_ECR_REPOSITORY_NAME=my-strands-agent
CONTAINER_IMAGE_TAG=latest
CONTAINER_EXECUTION_ROLE_ARN=arn:aws:iam::{account_id}:role/AmazonBedrockAgentCoreContainerRuntime-{region}
```

## 常用命令

### 验证前置条件
```bash
python scripts/check_runtime_prerequisites.py
```

### 创建 S3 Bucket
```bash
aws s3 mb s3://bedrock-agentcore-code-{account_id}-{region} --region us-west-2
```

### 列出已部署的 Runtime
```bash
aws bedrock-agentcore-control list-agent-runtimes --region us-west-2
```

### 查看 Runtime 详情
```bash
aws bedrock-agentcore-control get-agent-runtime \
  --agent-runtime-id {runtime_id} \
  --agent-runtime-version 1 \
  --region us-west-2
```

### 删除 Runtime
```bash
aws bedrock-agentcore-control delete-agent-runtime \
  --agent-runtime-id {runtime_id} \
  --region us-west-2
```

### Container: 构建推送镜像
```bash
# 登录 ECR
aws ecr get-login-password --region us-west-2 | \
  docker login --username AWS --password-stdin \
  {account_id}.dkr.ecr.us-west-2.amazonaws.com

# 构建并推送
docker buildx build --platform linux/arm64 \
  -t {account_id}.dkr.ecr.us-west-2.amazonaws.com/{repo}:{tag} \
  --push .

# 验证镜像
aws ecr describe-images --repository-name {repo} --region us-west-2
```

## Runtime 状态说明

| 状态 | 含义 | 可操作 |
|-----|------|--------|
| CREATING | 创建中 | ❌ 等待 |
| READY | 就绪 | ✅ 可调用 |
| CREATE_FAILED | 创建失败 | ❌ 需删除 |
| UPDATING | 更新中 | ❌ 等待 |
| UPDATE_FAILED | 更新失败 | ❌ 需删除 |
| DELETING | 删除中 | ❌ 等待 |

## 故障排查清单

### 部署失败
- [ ] 检查环境变量是否完整
- [ ] 确认 AWS 凭证有效
- [ ] 验证 IAM 角色权限
- [ ] 确认 S3/ECR 资源存在
- [ ] 查看 CloudWatch Logs

### 调用失败
- [ ] Runtime 状态是否为 READY
- [ ] Session ID 长度 ≥33 字符
- [ ] Prompt 内容合法
- [ ] 网络连接正常
- [ ] Bedrock 模型配额未超限

### 状态异常
- [ ] 等待足够时间 (2-5 分钟)
- [ ] 检查部署包/镜像完整性
- [ ] 验证 Agent 代码无错误
- [ ] 确认 /invocations 和 /ping 端点实现正确

## 成本估算

### 按需计费
- Runtime 本身: **免费** (无闲置费用)
- 调用费用: 按实际使用的计算时间计费
- 存储费用:
  - S3: $0.023/GB/月
  - ECR: $0.10/GB/月

### 示例成本
假设每天调用 1000 次,每次执行 2 秒:
- 月调用时间: 1000 × 2 × 30 = 60,000 秒 ≈ 16.7 小时
- 预估成本: < $10/月
